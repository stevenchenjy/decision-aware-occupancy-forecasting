# Root Figure Status

The root figure directory is a provenance and presentation workspace. It is
not the manuscript figure source. The paper uses only the two assets in
[paper/manuscript/figures](../paper/manuscript/figures), documented in
[paper/figures/README.md](../paper/figures/README.md).

## Canonical saved-output support figures

Files regenerated by the hybrid artifact path, including
canonical_empty_metrics_comparison, canonical_policy_10pct_comparison,
risk_opportunity_validation_vs_test_diagnostic, hybrid_reliability_analysis,
hybrid_stable_window_sensitivity, hybrid_lightgbm_historical_same_day, and
paired uncertainty plots, describe the offline post-bin saved-output analysis.
They may support internal review only when their captions preserve all of these
conditions: uncalibrated scores, empirical camera-label conflict, and processed
load-proxy overlap rather than savings.

## Exploratory figures

Files beginning with decision_aware_joint, window_aware, forecast_optimal, or
interval_vs_window are retrospective validation-selected diagnostics. They
cannot be used as confirmed findings or promoted with the already inspected
test period. After an empirical retraining study, candidates must be selected
again on new validation data.

## Legacy or excluded figures

All other root figures generated by the LBNL full-pipeline path, including
energy_risk, threshold_policy, safe_shiftable_load, example_forecast, and
presentation variants, are legacy cleaned-release replay or historical
presentation artifacts. The replay is quarantined by scripts/run_all.py and is
not a prospective empirical rerun. Do not cite those figures in the paper or
use their legacy file names as scientific terminology.

## Archive

The figures/archive tree is retained solely for traceability and is excluded
from the active evidence base.
