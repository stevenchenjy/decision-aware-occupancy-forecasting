Data provenance and interpretation

The demo uses the cleaned LBNL Building 59 release and the repository's saved test predictions. Its hybrid uses the fixed weights 0.15 historical schedule, 0.60 LightGBM, and 0.25 compact Transformer. It does not select new weights or fit a controller. The reported thresholds met a 10% empirical validation conflict cutoff, which is not a guarantee about future risk.

Moving the controls explores an already inspected test period. It cannot establish a better held-out policy or new confirmed results. Source timestamp provenance, upstream imputation, corrected deep-model initialization, and evaluation on fresh data remain necessary for a prospective study.
